## 編集のしかた

- 「原稿」列を書き換えてください。行の追加・削除も自由です（新しい行の ID は空欄で構いません）。

- 「今の長さ」は、V08 / V15 で読んだときのおおよその秒数です。枠を超えた行は最大 1.2 倍速まで速めて収めますが、早口になるので、文を短くするのがおすすめです。
