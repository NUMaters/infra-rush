# 渡橋後の進軍と並行妨害

ユーザーの実プレイから、橋を渡り終えたBotまで橋崩壊で帰還する挙動と、相手の橋で行う盛土・破壊が施工ロックに妨げられる挙動を修正した。既存仕様書の「進路を失ったBotは帰還」「ひとつの地点で同時に1体」は、今回の明示的な要望に合わせて変更した。

進軍Botの経路は「手前岸・対岸・城手前・城」の順。対岸の経由点を通過した後は橋の通行可否を再検査せず、攻撃を続ける。対岸に着く前は従来通り帰還する。盛土と橋梁破壊は施工ロックを取得せず、架橋・補強・修繕・整地と並行できる。完了時点で対象がなくなった作業や既に完成した盛土は資源を返す。1人用のTypeScriptとオンライン用のGoで同じ判定にする。

橋の現在強度は破壊・地震ごとに1だけ下がり、0で崩壊する。損傷段階は「補強上限 − 現在強度」に揃え、修繕途中もひびが残り、2段階の損傷では欠けと露出した鉄筋を表示する。石アイコンの点滅は毎フレームのDOM再生成が原因だったため、内容が変わる時だけ更新する。作業パネルは2列の最小幅を固定し、横スクロールを生む長い理由文を短く表示する。
