# 支給された油圧ショベルの統合

支給モデルの外観を採用する。元GLBにはアニメーションも関節名もなく、ゲーム側の旧関節角度を直接適用するとバケットが車体に入り込んだ。そのためBlenderで車体・旋回体・一体アーム・バケットの親子関係とBot搭乗位置を追加し、施工サイクルの角度を実際のレンダーで調整した。

アームの一体造形を無理に自動分割すると、油圧ホースや外装が空中へ分離した。独立した肘の動きより、支給モデルの形状維持と自然な採掘動作を優先した。将来はBlenderで肘周辺を手動で再モデリングしてから独立可動化する。

支給テクスチャの青い塗装はランタイムの単純なマテリアル色変更では赤にできないため、彩度の高い青塗装の画素のみを赤へ変換したGLBを追加した。初回の色変換は窓と運転席の青灰色も拾って赤くしていたため、青の彩度と明るさの条件を絞った。ガラス、白いキャビン、暗い履帯、橙の金具と可動ピボットは保持する。赤チームはこの派生モデルを読み込む。

ブーム側の窓は支給モデルで別々の薄いメッシュ（part 17・23）だが、元は不透明な青いテクスチャだった。両面を薄い中性色の透過材にし、ゲームで搭乗Botが見えるようにした。赤チームのアーム内側は、ブームの部品1・14に限って影色の青も赤へ変換する。全体の色判定を広げると窓や運転席まで染まるため、部品単位で扱う。
