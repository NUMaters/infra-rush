# GitHub Pages と公開対戦サーバー（2026-09-26）

GitHub Pages は静的配信のみで、同一ホストの `/ws` に Go サーバーを置けない。公開画面の WebSocket URL はビルド時の `VITE_ONLINE_WS_URL` で指定する。URL 未設定の Pages では接続を繰り返さず、対戦サーバーの設定が必要と表示する。ローカルプレビューと Go サーバー自身による配信では従来の接続先を保つ。

Goサーバーは `INFRA_ALLOWED_ORIGINS` に列挙された HTTPS ページだけを別ホストから受け付ける。同一ホストとローカルプレビューの接続も保つ。任意のオリジンを許可しない。

公開ホストはまだ未決定。配置には課金先となる専用プロジェクトの選択が必要であり、配置後は2ブラウザで公開URLを使った対戦を確認する。
