# 試合開始演出と閉じる操作

仕様書にない開始演出は、試合ルールを変えずに参加者へ自陣と相手陣を知らせるために追加した。味方チームと相手チームを各1.5秒見せ、3・2・1を各1秒、GOを0.6秒表示する。演出時間は `master/game.json` の `introSeconds` で管理する。1人プレイ中は演出が終わるまでCPUと試合時計を停止する。オンラインではサーバーが両者へ共通の開始時刻を送り、それまでは試合時計・Bot指示を受け付けない。途中で相手が部屋を出た場合は勝敗を付けず待機画面へ戻す。

遊び方・一時停止・オンライン待機画面は、ボタンに加えて背景部分のタップでも閉じる。Botの作業パネルは何もないマップをタップすると閉じる。カードやボタンの中をタップしただけでは閉じない。
