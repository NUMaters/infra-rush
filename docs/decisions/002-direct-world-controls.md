# 直接操作と自動施工対象（2026-09-26）

ユーザーの変更依頼に基づく。ゲームルール、資源・時間・CPUの仕様は変更しない。

- 初期視点は青チームが手前。地形・城・採石場の論理座標はそのまま、カメラを反対側から向ける。
- 1本指/左ドラッグで平行移動、ホイール/ピンチでズーム、右ドラッグ/2本指ドラッグで回転。当初は補助ボタンも用意したが、操作が直感的に分かるため撤去した（[004](004-player-facing-language-and-health.md)）。
- ドラッグ・複数指操作の終了をBotへのタップとして扱わない。OrbitControlsを使用し、既存のThree.js以外の依存は増やさない。
- 下部Botカードを撤去し、3D上のBot・搭乗重機のタップで指示。数字キー1〜5のショートカットは維持。
- 指示ウィンドウは幅280px以下、Bot付近に配置し画面内に収める。タスクは2列、橋選択タブは撤去。
- 通常のBot選択では架橋・補強・修繕・整地は自軍専用橋、盛土・破壊は敵軍専用橋。表示コスト・有効条件・実行先に同じ解決関数を使う。
- 中央橋の戦略を失わないよう、中央橋をマップ上で直接タップすると中央橋への施工を開く。Botを直接選び直すと通常の自動対象に戻る。
