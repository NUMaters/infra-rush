# オンライン対戦と待機室（2026-09-26）

ユーザー指定の「ランダム」か「部屋をロック」をタイトルから選ぶ。ランダム選択者だけを待機列に入れて先着の2人を組み合わせる。ロックされた部屋には推測しにくい英数字5文字のIDを発行し、そのIDを入力した相手だけが参加する。両者が揃った後に名前を編集し、双方の準備完了で試合を開始する。未入力時は「プレイヤー1」「プレイヤー2」。再戦は双方の意思表示後、同じ部屋を準備画面へ戻す。

Goサーバーが50msごとに仕様書のマスターデータを使ってBot・資源・橋・地震・城HP・勝敗を更新し、WebSocketで状態を配る。クライアントは指示だけ送る。所属チームは接続時にサーバーが決め、Bot所有権とコストを検証する。指示には連番を付け、重複実行を防ぐ。画面側は受け取ったBot位置を補間する。切断後は同じセッショントークンで30秒以内に復帰できる。相手が帰らなければ退出扱いにする。部屋を放置した場合は一定時間後に解放する。

ローカル静的プレビューの5177番からでも8080番のGoサーバーへ接続できる。Goサーバー自身も静的ファイルを配信できるため、本番では同じホストで画面とWebSocketを公開する。公開先の決定とHTTPS/WSS設定は別途必要。Phase 1の全品質条件が満たされたという意味ではなく、ユーザーからの明示的なPhase 2着手指示を優先した。
