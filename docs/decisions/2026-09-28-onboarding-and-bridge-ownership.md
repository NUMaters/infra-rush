# チュートリアルと橋の所有表示

プレイヤーが橋の取り合いと複数Botの使い方を理解しづらいというフィードバックを受け、操作練習の順序をルール→3橋の役割→カメラ→2体同時採掘→架橋→強化・修繕→進軍・帰還→盛土→破壊→整地とした。手前・中央・奥の役割は短い色付き図で示す。補強後の修繕では練習用の橋を1段階傷める。資源や損傷の補助はチュートリアルの一時的な試合状態に限り、本番は新しい状態から開始する。整地まで操作して完了する構成を維持し、スキップは常時可能にする。

橋に直接触れたときの作業対象は、その橋を明示的に選んだものとして固定する。Botから「橋をつくる」を選んだときは、自陣の橋が完成済みなら中央を対象にする。橋に別のBotがいて施工できない場合も他の橋へ黙って切り替えず、その対象で理由を示す。橋の所有者は石橋・鉄橋のどちらでも手すりと旗の色で示し、耐久がなくなったら表示を消す。

ショベルの暗さは材質の金属反射に加え、採石場の前景の岩に車体が隠れる構図が大きかった。塗装画像を維持したまま発光補助と粗さを調整し、採掘中の車体を岩の開口部側へ寄せる。バケットが対象の岩に届く範囲で、青・赤それぞれのカメラ角度を画像で確認する。
