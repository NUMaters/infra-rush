# 018 — 施工の接地感と対戦復帰

- 作業中の重機は、車体だけを揺らすのではなく、ショベルのブーム・アーム・バケット、掘削機の回転刃、グレーダーとブルドーザーのブレードを独立して動かす。ドリルの刃とグレーダーのブレードはBlenderの独立ピボットとしてGLBへ出力する。搭乗Botの腕とハンドルも同期させる。これにより施工対象との関係が画面上で読める。
- 対戦中の切断猶予は90秒とする。スマホでブラウザを閉じて開き直し、3Dアセットを再読込する時間を確保するため。試合トークンと直近の対戦時刻を端末内に保持し、猶予内の再アクセスでは自動復帰を試みる。明示的に退出した場合と試合終了時には復帰情報を消す。
- 相手の切断は、相手の城付近に通信アイコンを表示する。相手が戻ったことはルーム状態の接続フラグから判定し、表示を消す。
- タイトルBGMはページ読込時に再生を試みる。ブラウザが音声の自動再生を制限する場合は、画面上の最初のタップまたはキー入力で再開する。
