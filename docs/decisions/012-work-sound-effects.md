# 土木作業の効果音

2026-09-27。採掘・架橋と補強／修繕・盛土・整地・橋破壊には、作業中に繰り返す短い効果音を付ける。採掘は土を削るノイズと金属の当たり、架橋は金属の打撃、破壊はドリルと砕ける音を基調とする。施工完了時は既存の完了音を使う。

音は Web Audio で生成し、BGM用音声ファイルとは別に管理する。原音は小さなノイズバッファと短いオシレーターだけで、追加ダウンロードを必要としない。繰り返しに少しだけピッチ変化を付け、同時に複数Botが働く際は優先度に従い一つの作業音だけを鳴らす。自分のBotの作業を対象とし、対戦開始前・一時停止・ミュート中は新しい作業音を鳴らさない。資源獲得の通知音も短い間隔でまとめ、多数のBotの音が重ならないようにする。
