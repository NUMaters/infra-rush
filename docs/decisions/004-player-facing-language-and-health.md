# 画面の言葉と城の残り表示（2026-09-26）

ユーザーから、右側の視点操作ボタンは不要、ハート列のライフ表示を改善したい、仕様書由来の言葉（「青専用橋」「中央共有」など）が画面では不自然、という指摘があった。

- カメラはドラッグ・ピンチ・ホイール・右ドラッグ・2本指操作で動くため、右側の5ボタンを撤去する。遊び方には操作を短く記載する。
- 城は残り回数を「5/5」と5区切りのゲージで表示する。被弾時にカードが一瞬反応する。内部のHP=5と勝敗判定は変更しない。
- 橋の内部ID・所有権・施工条件はそのまま。マップ上では「橋をつくる」「渡れる」「ふさがれている」など行動と状態を表示し、橋を識別する必要がある支援技術には「自分の城につながる橋」「真ん中の橋」「相手の城につながる橋」を使う。
- Botへの指示は「掘る」「橋をつくる」「強くする」「直す」「道をふさぐ」「土をどける」「橋を壊す」「攻める」とし、資源不足などの説明も普通の言葉にする。仕様書の作業分類は設計・データ・開発文書で維持する。
