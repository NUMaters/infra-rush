# ショベルカーの自然な動き

ユーザーから「プレイ中のショベルカーの動きが変。アームが本体にめり込むくらい傾いている」との指摘があった。調べると、採掘中の関節角度がバケット比率修正後のモデルに合っておらず、アームとバケットが運転席・車体に食い込み、バケットは地面に届かないまま上下していた。ブーム・アーム・バケットが同じ正弦波で同時に往復するだけで、掘る動作に見えなかった。また、移動中に経路の曲がり角や作業開始の瞬間に車体の向きが一瞬で切り替わっていた。

採掘中は実機の掘削サイクルに合わせ、「バケットを開いて地面に食い込ませる → アームを引き寄せながらバケットを巻き込む → ブームを上げる → 上部旋回体を横へ旋回 → バケットを開いて放土 → 旋回して戻る」を約4.4秒で繰り返す。各キーポーズの間は緩急をつけて補間する。放土側はBotごとに左右を分け、隣り合う重機が同じ動きにならないようにする。移動中はアームを畳み、バケットをクローラー前方の地面から浮かせて運ぶ。移動と作業の切り替えではポーズを滑らかに移す。

向きは瞬時に変えず、近い回り方向へ減衰補間する。重機は履帯でその場旋回するため、歩くBotより遅く向きを変える。見た目だけの変更で、ゲームルールとTypeScript・Goの判定は変えない。関節角度は `src/render/excavator-motion.ts` にまとめる。キーポーズと、その間および移動姿勢との補間途中で、アーム・バケットの頂点が運転席・ミラー・車体・クローラーの範囲に入らないことをブラウザ上で確認した。
