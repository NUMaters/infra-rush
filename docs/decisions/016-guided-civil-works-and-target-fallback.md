# Guided civil works and automatic bridge targets

The single-player practice match now starts with the live game's rules, then guides one action at a time through mining, bridge construction, marching, embankment, demolition, and grading. The construction step shows the 50-stone payment with the existing resource artwork. Mining gains use those same icons. The practice match is discarded before the CPU match starts, so its prepared resources and bridges never carry over.

The later practice steps need a ready enemy bridge and a blocked home route. After the first attack returns, practice alone prepares an enemy level-one bridge and the soil and iron needed for the three lessons. After demolition, practice alone blocks the home bridge for the grading lesson. These are teaching fixtures, not CPU-match resource grants.

Sabotage and grading choose an eligible bridge at command time. When the contested bridge is occupied or already blocked for embankment, commands fall back to the opponent's dedicated bridge; when that bridge is unavailable, commands can target an eligible contested bridge. Disabled buttons show the exact command reason so a temporary lock or missing bridge is distinguishable from missing resources.

Decorative trees, rocks, and flowers are excluded from sampled road corridors, with extra clearance for tree canopies. This preserves the existing island layout while keeping routes legible.
