# 試合 BGM と施工効果音の改善（2026-09-28）

試合中の軽い曲調を見直し、低いベース、控えめな短調の旋律、厚みのある打楽器で通常戦のループを作り直した。自分の城の残り HP が最大値の **1/3 未満**になると、テンポを上げて刻みを増やした危機時の曲へクロスフェードする。城 HP が 15 の現行設定では 4 以下で切り替わる。相手の城が減っただけでは切り替えない。タイトル、勝敗の曲は引き続き専用音源を使う。

両曲は `scripts/generate-game-music.mjs` から決定的に再生成できるオリジナル音源で、外部サンプルや既存曲は使わない。`ffmpeg` の MP3 エンコーダーが必要。旧 `assets/audio/build_music.py` は従来の軽い試合曲の生成用であり、現行の試合曲の再生成には使用しない。PWA のアセットキャッシュには新しい危機時の音源を追加し、キャッシュ版を更新した。

施工効果音は、採掘・架橋・盛土・整地・破壊ごとに、フィルターをかけた摩擦音と低い打撃音、短く減衰する金属の倍音を組み合わせた。作業間隔を少し詰め、ピッチ変化と一種類のみの優先再生で、複数 Bot の音が密集しないようにする。完了音も高い単音中心から、低い打撃音に短い上昇音を重ねる形へ変更した。ミュート・一時停止中は作業音と BGM の扱いを従来どおり維持する。
