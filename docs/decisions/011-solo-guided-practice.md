# 1人プレイ前の操作練習

2026-09-27。1人プレイの初回開始では、通常のルールと同じ操作で「Botを選ぶ → 掘る → 自分の橋をつくる → 攻める → 城を一度たたいて帰る」を体験する。案内は現在の操作に合わせて切り替え、対象のBot・橋・ボタンを光で示す。案内中は常に「スキップして対戦」を表示する。

練習は独立した試合状態で行い、CPU、地震、制限時間を止める。橋の費用まで残り2個の石を初期所持させ、採掘の成果を一度確認してから架橋へ進める。これは待ち時間を短くする練習用設定であり、通常対戦のマスターデータや難易度は変えない。練習を終えるかスキップしたら、新しい試合状態を作り、既存のチーム紹介とカウントダウンを経てCPU戦を始める。練習中の石、橋、城ダメージは持ち越さない。再戦は練習を繰り返さず通常対戦へ進む。
