# 試合終了後のマップ確認と重機描画の安定化

提供された重機GLBには、グレーダー1色分だけでも387枚の画像が含まれる。大半は塗装画像と対になった法線画像で、青赤の全車種とリザルトの別WebGLビューを使った後はモバイルGPUのテクスチャ使用量が大きくなる。iPhoneで重機だけが黒く見える報告を受け、ゲーム画面と豆知識ビューでは塗装画像と形状を維持し、法線・金属度・粗さ・遮蔽の補助画像をGPUへ送らない。豆知識ビューを閉じる際はそのWebGLコンテキストも明示的に解放する。元のGLBは変更しない。

長時間のタイトル背景を撮影すると、CPUが橋をかける前に5体を同じ採石場へ送るため、大型ショベル同士が重なって影が黒い塊になる現象も確認できた。タイトル背景ではチームにつき1台の採掘重機だけを描き、他の作業者はBotとして見せる。対戦中のBot数や採掘速度は変更しない。画面切り替えや作業終了時には描画専用の桁・選択リングを解放し、前の試合のリグを持ち越さない。

リザルトから「試合の最後を見る」を選ぶと、確定済みの同じゲーム状態をマップに表示する。シミュレーションは終了したままなので資源や勝敗は変化しない。カメラの移動・拡大・回転は使え、「結果へ戻る」でアンケート回答と豆知識を含むリザルトに戻る。チュートリアルはルール説明の直後にカメラ操作の案内を追加し、スキップは従来どおり常時可能とする。

補助テクスチャを外した後の重機は色とシルエットをスマホ寸法の作業画面で比較した。実機iOSでのGPU再現確認は端末未接続のため残る。
