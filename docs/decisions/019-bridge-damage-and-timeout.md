# 橋の損傷・地震・時間切れ

- 橋の見た目は最後に施工した型で維持する。鉄橋が損傷して強度1になっても石橋へ戻さず、ひび・欠け・露出した補強材を段階的に重ねる。Driveの石橋・鉄橋損傷シートの読みやすさを優先し、破損部分は軽量な3Dジオメトリで描く。
- 地震では完成済みの橋の強度を必ず1下げる。強度1の橋は崩壊し、未施工地点も含む盛土をすべて取り除く。両クライアントとGoサーバーが共通のマスターデータを参照する。
- 相手専用の架橋地点は、橋の完成前でも盛土できる。架橋後も盛土は残り、所有者が整地するまで通れない。中央は所有者が決まってから盛土できる。
- 制限時間終了時は城HPの多い側が勝ち、同点だけ引き分けとする。
