# Opening playback and tutorial language

The mobile opening had two independent failure modes: the HTML shell no longer supplied a video source until the application module ran, and the loading overlay disappeared as soon as all GLBs were ready, even if the video had just started. Safari can also reject muted autoplay in some device states. The shell now declares a mobile light source up front, the application keeps the opening visible for at least 3.5 seconds of actual playback, and a rejected or stalled autoplay exposes a tap-to-play button. A skip button becomes available once the game is ready. The poster remains the visual fallback.

The opening image/video is scaled within its clipped full-screen background by 1.28 so the construction scene reads larger on portrait phones. The title's CPU-vs-CPU simulation now advances at real time instead of four times real time.

All tutorial descriptions were reviewed against the current master costs and task rules. Each instruction now states the immediate action and its effect in natural Japanese, including the central bridge prerequisite, the one-level effects of bridge damage and earthquakes, resource spending, return to the castle, and simultaneous Bot work. The stage order and gameplay rules are unchanged.
