# v0.1の補完判断

- 初期橋は石50（中央石60）。20節の「鉄獲得」は6節・14節の具体定義と不整合があるため、具体定義を優先。鉄は補強・整地等に使用。
- 採掘は1秒1資源、石→土→石→鉄の固定周期。採石場は一箇所のまま。全員採掘なら初橋用の石は約20秒＋移動。種別の偏りは全チーム同一で再現可能。
- 橋は最高施工レベル(capacity)と現在強度(level)を分ける。ドリルで1段階減少、0で崩落。修繕で1段階戻せる。補強は無損傷時のみ最高施工レベルを増加。地震は最低Lv1を維持し、Lv1では視覚的損傷のみ。視覚損傷も修繕対象。
- 橋出口の盛土は橋ごとに1箇所。敵所有橋へ施工し、所有側が整地できる。中央橋は所有側のみ通行可（所有の意味を明確にする）。中央橋施工予約は先着1体で排他し、相手の二重払いを防ぐ。
- 施工費は指示受理時に引落し。作業対象が他施工で消滅した場合は費用全額返却して帰還。通常キャンセルできるのは採掘のみ。進軍は移動中の経路喪失も即帰還。
- 地震の発生時間・対象はseed付きPRNG。360秒あたり期待1回の指数分布で、事前警告。強度確率は仕様通り50/30/15%。
- 時間切れはHP差にかかわらず引き分け。先に5回殴った側が勝利。
- CPUは同じcommand関数経由、隠れた資源/速度ボーナスなし。難易度は判断間隔・採掘人数・補修優先・中央橋/妨害判断のみ。

- 初回の実プレイで、操作を覚える間にeasy CPUが約114秒で勝利することを確認。easyは開始後25秒、normalは5秒、hardは0秒で判断を開始する。資源・速度は変更せず、初動の判断猶予を難易度に含める。
