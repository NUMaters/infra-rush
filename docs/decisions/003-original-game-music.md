# オリジナルBGM（2026-09-26）

この記録は最初の曲の制作経緯。現在の試合 BGM と危機時の切り替えは [024-dynamic-game-audio.md](024-dynamic-game-audio.md) を参照。

仕様書の「SE/BGM/エフェクト」に対応する。世界観に合わせ、軽快なマレット、ベル、柔らかいコード、ベース、控えめな打楽器で約58秒のオリジナルループを制作した。音声サンプルや既存曲は使用せず、`assets/audio/build_music.py` から再生成できる。MP3を使い、スマートフォンでも単一の圧縮ファイルを読む。

試合BGMは開始操作後に再生する。ポーズ・遊び方で一時停止する。音声ボタンはBGMとSEの双方を切り替える。BGMは同じAudioContextのGainNodeを通し、効果音を聞き取りやすい低めの音量に設定する。

曲は32小節・132BPMで、8小節ごとにメロディと密度を変える。中央部で音数を下げ、後半に主旋律が戻る構成にして、6分間の試合での単調さを抑える。

タイトル、勝利、敗北・引き分けにも、それぞれ短いオリジナルループを追加した。`scripts/generate_scene_music.py` から再生成でき、画面遷移に合わせて音量をクロスフェードする。タイトルは明るい予感、勝利はファンファーレ、敗北・引き分けは再戦を促す柔らかい曲調にした。タイトル画面でも再生を試みるが、初回の自動再生をブラウザが拒否した場合は最初の操作で音声を開始する。右上の音声ボタンを最初に押した場合はミュートにせず、再生開始の操作として扱う。
