# CPU戦の体感難易度フィードバック

CPU戦の結果画面で「今回のCPU、どう感じた？」を任意で尋ねる。選択肢は「かんたん」「ふつう」「むずかしい」。ユーザーが対戦前に選んだ難易度と、対戦後の体感を別々に保存する。回答を強制せず、オンライン対戦とチュートリアルには表示しない。

回答にはランダムな試合ID、選択したCPUの強さ、体感、勝敗、試合時間、双方の城HPだけを含める。名前、招待コード、端末識別子は送信しない。ブラウザ側の未送信分は最大20件まで保存し、再起動・オンライン復帰時に再送する。Goサーバー側でIDを重複排除し、Fly.ioの暗号化された1GBの永続ボリュームにJSON Lines形式で保存する。データを閲覧する公開APIは設けない。

集計時には `python3 scripts/feedback-report.py feedback.jsonl` を使う。難易度ごとの体感回答数、勝敗数、試合時間の中央値を確認し、少数の回答だけでCPUパラメータを変えない。初心者と熟練者では同じCPUでも体感が異なるため、自己申告は「調整の材料」であって絶対的な正解ではない。またCPU戦の結果・HPはブラウザからの自己申告であり、サーバー検証済みの対戦記録ではない。

既存の難易度値は、回答が蓄積されるまでは維持する。調整時は `master/cpu.json` の判断間隔、進軍人数、初動時間などを変更し、試合テストで勝率や詰み状態を確認する。プレイヤーの資源やCPUの隠しボーナスは変えない。

ボリュームはマシン停止中も容量分が課金される。保存済みデータを移動せずにボリュームを削除・再作成しない。
