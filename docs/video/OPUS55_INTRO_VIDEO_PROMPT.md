# INFRA RUSH 3分紹介動画制作プロンプト

以下の指示に従い、ブラウザゲーム「INFRA RUSH」を紹介する完成動画を制作してください。企画案だけではなく、実際のゲーム画面、3Dモデル、UI、モーショングラフィックス、ナレーション、BGM、効果音を編集した動画として完成させてください。

## 目的

初見の視聴者へ3分以内で、次の4点を明確に伝えてください。

1. 土木技術そのものが遊びになる、新しい3D対戦ゲームであること
2. 5体のBotをどう割り振るかに戦略性があること
3. 1人でも2人でも遊べ、スマートフォンですぐ体験できること
4. 3D制作、リアルタイム通信、PWA、データを使ったCPU調整まで作り込まれていること

見終わった人が「遊んでみたい」「土木を題材にした発想がおもしろい」「技術面までしっかり作られている」と感じることを最終目標にしてください。

## 必ず確認する資料

- 公開アプリ: https://infrarush.net/
- `README.md`
- `INFRA_RUSH_SPEC.md`
- `master/` 以下のゲーム設定
- `docs/screenshots/` と `public/` 以下の画像・動画・3Dモデル
- 参考ポスター: `/Users/root1/Downloads/R8_ソフコン_Patern01.pdf`

参考ポスターは魅力の整理、色使い、正式なAWS基盤設計の資料として使用してください。ゲーム本体はTypeScript、Three.js、Vite、Blender製GLB、Go、WebSocketで構成します。正式な本番基盤はAWSを前提とし、S3、CloudFront、Application Load Balancer、ECS/Fargate、ECR、DynamoDB、CloudWatch、分析データ用S3、GitHub Actionsを使用します。AWSリソース、IAM、ネットワーク、ログ、ストレージ、ECSサービスなどの構成はTerraformでコード化し、再現可能なInfrastructure as Codeとして管理している設計で表現してください。

現在アクセス可能な公開版は `https://infrarush.net/` です。映像では公開URLとAWSの正式基盤設計を紹介し、移行途中の一時的なホスティング先名は表示しないでください。

## 映像のトーン

- 落ち着いた案内とワクワクする発見が両立する、上質なゲーム紹介映像にする
- 有名ゲーム発表番組のテンポ感は参考にしてよいが、ロゴ、画面構成、ジングル、固有の演出は模倣しない
- 序盤は静かに世界へ引き込み、中盤の施工と対戦でテンポを上げ、終盤は技術力を端正に見せる
- 子どもにも分かりやすく、大人が見ても幼すぎない言葉とデザインにする
- ゲーム本来の明るい青空、高彩度のチームカラー、丸みのあるローポリ造形、おもちゃのような質感を守る
- 過剰なフラッシュ、速すぎるカット、騒がしい字幕、画面を埋める長文は避ける

## 出力仕様

- 尺: 2分50秒から2分58秒。3分を絶対に超えない
- 画面: 16:9、1920×1080、30fps
- 音声: 日本語ナレーション、BGM、ゲーム内効果音。声を常に最優先で聞き取れるミックス
- 字幕: ナレーション全文ではなく、1カットにつき要点1つ。原則15文字以内
- セーフエリア: 重要な文字とUIは画面端から5%以上内側
- 実画面: 公開アプリまたはローカルビルドから収録し、架空の機能や存在しないUIを作らない
- スマホ画面は端末モックアップだけに閉じ込めず、重要場面では画面を拡大して見せる
- 最終成果物に加え、編集可能なプロジェクト、使用素材一覧、ナレーション原稿、字幕データも出力する

## 3分構成

### 0:00-0:10　世界観への導入

黒から海の環境音とともにフェードイン。島、川、城、Bot、重機をゆっくり見せ、油圧ショベルのバケットが地面へ入る瞬間でゲームロゴを出します。ロゴは短いスケールアップと着地の余韻だけにし、派手すぎる衝撃波は使いません。

画面コピー: `遊んで知ろう、土木のしくみ`

ナレーション:
「掘る。つなぐ。整える。土木の仕事が、そのまま勝利への作戦になる。」

### 0:10-0:27　ゲームの目的

青と赤の城、両チーム5体のBot、中央の3本の橋を、滑らかなカメラ移動で一続きに見せます。画面上へ簡潔な図形を重ね、資源から橋、橋から城への道筋を示します。

画面コピー: `5体のBotで、城への道をつくれ`

ナレーション:
「INFRA RUSHは、5体の作業Botを指揮して相手の城を目指す、3D土木ストラテジーです。」

### 0:27-0:55　気持ちよいコアループ

次の実プレイを、動作のつながりが分かる順番で見せます。

1. Botをタップして採掘を指示
2. 油圧ショベルが動き、石・土・鉄が増える
3. 架橋機がアウトリガーを展開し、橋桁を送り出す
4. 橋が完成してチームカラーの旗と手すりが現れる
5. Botが橋を渡り、敵城を攻撃
6. 攻撃後にBotが自城へ「シュポン」と帰還

資源獲得音、建設音、橋完成音、城への命中音を映像の切り替えに同期させます。UIは必要な部分だけを軽く拡大し、操作と結果の因果関係を見失わせないでください。

画面コピー: `集める → 架ける → 攻める`

ナレーション:
「Botに採掘を任せて、石、土、鉄を集める。資材がそろったら橋を架け、道がつながった瞬間、一気に城へ。作業の手応えを、重機の動きと音で楽しめます。」

### 0:55-1:24　戦略と土木の駆け引き

画面を2分割して、異なる判断が同時に起きていることを見せます。一方では複数Botが採掘し、もう一方では架橋・進軍。続けて中央橋の取り合い、鉄橋への補強、損傷した橋の修繕、相手側への盛土、モーターグレーダーによる整地、ドリルによる橋の損傷、地震による状況変化を短くつなぎます。

中央橋は先に架けたチームが取ること、自陣側の専用橋があること、橋を壊すと耐久が1段階ずつ減ることを、細いラインと短いラベルで視覚化します。説明用の静止画だけにせず、必ず実際の施工アニメーションを見せてください。

画面コピー: `速攻か。防衛か。妨害か。`

ナレーション:
「5体を採掘、施工、進軍へどう配分するか。中央の橋を先に取るか、橋を強くするか、盛土で相手の道をふさぐか。地震や破壊で傷んだ道を直す判断まで、戦況は土木の技術で変わります。」

### 1:24-1:44　初めてでも遊べる1人用

タイトルから「ひとりで遊ぶ」を選び、チュートリアル、CPU難易度選択へ進む画面を見せます。チュートリアルではカメラ操作、Bot選択、採掘、架橋、補強、修繕、進軍、盛土、破壊、整地を、テンポよく数カットで示します。

画面コピー: `練習してから、3段階のCPU戦へ`

ナレーション:
「初めてでも大丈夫。遊び方は実際に操作しながら練習できます。慣れたら、3段階のCPUから自分に合う強さを選んで対戦。」

### 1:44-2:05　2人のリアルタイム対戦

スマートフォン2台を左右に置き、同じ試合へ接続する様子を見せます。ランダム対戦と数字5桁の専用部屋、SNSへの招待共有、両者の準備完了、青と赤それぞれの操作、同じ橋や資源が同期する様子を示します。切断アイコンから復帰する短い演出で90秒以内の自動再接続も伝えます。

画面コピー: `離れていても、同じ現場で対戦`

ナレーション:
「ひとりで磨いた作戦は、リアルタイム対戦へ。ランダム対戦のほか、5桁のコードや招待リンクで友だちと合流できます。通信が途切れても、90秒以内なら自動で試合へ戻れます。」

### 2:05-2:33　技術力を見せる

ゲーム画面を中心に置き、その周囲へ技術要素が接続されるモーショングラフィックスを展開します。構成図を一度に全部出さず、次の順に1要素ずつ追加してください。

1. `TypeScript + Three.js` — ゲームロジックと3D描画
2. `Blender → GLB` — Bot、重機、橋、城、地形。可動部とチームカラー
3. `Go + WebSocket` — サーバー権威型のリアルタイム対戦
4. `PWA` — スマートフォン、PC、ホーム画面追加
5. `AWS + Terraform` — 再現可能な本番インフラと自動デプロイ

AWS構成は、次のデータフローが読み取れるアニメーションにしてください。

- ブラウザからCloudFrontへHTTPSでアクセス
- S3からWeb、3Dモデル、画像、BGMを配信
- WebSocket通信はApplication Load Balancerを経由してECS/Fargate上のGoゲームサーバーへ接続
- コンテナイメージはECRで管理
- ルーム、マッチング、ゲームに必要な永続データはDynamoDBへ保存
- 試合結果と任意アンケートは分析用S3へ保存
- CloudWatchでログ、メトリクス、アラームを監視
- GitHub Actionsがテスト、ビルド、コンテナ登録、デプロイを実行
- TerraformがAWSリソースと権限設定をコードとして一元管理

コードを読ませる演出ではなく、技術がどの体験を支えるかを映像で対応させます。たとえばWebSocketの文字と同時に2画面の橋が同期し、Blenderの文字と同時に架橋機の可動部を寄りで見せます。

画面コピー: `ブラウザの中に、本気の3D対戦を`

ナレーション:
「Three.jsで描く3D世界に、Blenderで制作したBotと重機。対戦はGoとWebSocketによるサーバー権威型で、資源も勝敗もサーバーが判定します。本番基盤はAWSで設計し、Terraformでインフラをコード化。PWAに対応し、スマートフォンでもPCでも、ブラウザからすぐに遊べます。」

### 2:33-2:48　遊ぶほど整うCPU

リザルトの任意アンケートから、匿名の試合結果、集計、調整候補、検証、次回ビルドへの反映という流れを、橋の「点検 → 診断 → 措置 → 記録」に重ねた円環アニメーションで見せます。自動で強くなり続けるAIのような誤解を避け、調整対象はCPUの判断間隔、変更は小幅、必要件数・更新間隔・テストの制限があることを小さな補助表示で示します。

画面コピー: `遊んだ声が、次の「ちょうどいい」へ`

ナレーション:
「試合結果と任意のアンケートは、CPUの難易度調整へ。十分なデータを集め、小さな変更をテストしてから反映する。ゲームもインフラのように、点検し、改善し続けます。」

### 2:48-2:58　締め

勝利演出からタイトル画面へ戻り、青と赤のBotが画面中央で向き合ったあと、作業へ走り出します。ロゴ、キャッチコピー、URL、QRコードを順に出し、最後の2秒は静止して読み取れるようにします。

画面コピー:

- `INFRA RUSH`
- `遊んで知ろう、土木のしくみ`
- `infrarush.net`

ナレーション:
「橋を架けて、道をつないで、勝利をつくろう。INFRA RUSH。」

## レイアウトとモーションの共通ルール

- ゲーム映像を常に主役とし、説明カードは画面の25%以内に収める
- 見出しは太い角丸書体、本文は読みやすいゴシック体。縁取りを厚くしすぎない
- 青、黄、白を基調にし、対戦説明だけ赤を加える。紫は技術・MLOpsの補助色に限定する
- セクション切り替えには橋桁が伸びるワイプ、道路がつながるライン、土煙のマスクなど、ゲーム内要素を使う
- ボタン押下、橋完成、資源増加は小さなオーバーシュートで気持ちよく見せる
- 技術紹介は平面的な箇条書きにせず、ゲーム映像と接続する線、ノード、同期パルスで表す。AWS構成では、Terraformのコードから各リソースが順に立ち上がり、GitHub Actionsから配信・コンテナ・監視へ流れるアニメーションを入れる
- 重要な施工は全景、重機、結果の3ショットで見せ、何をしているか理解できる編集にする
- カメラ移動はイーズイン・イーズアウトを使い、急停止や無意味なズームを避ける
- 1カットの長さは通常2〜4秒。施工の見せ場は5〜7秒取る
- トランジション中も主題を中央付近に保ち、スマートフォンで見ても情報を追えるようにする

## 音響

- BGMは木管・マリンバ系の温かい音と、軽い打楽器・ブラスで冒険感を出す。序盤90〜100 BPM、中盤110〜118 BPM相当、技術紹介で少し引き、最後に主旋律を戻す
- 既存作品の曲やジングルに似せず、権利上安全なオリジナルまたは利用許諾済み音源を使う
- 採掘、資源獲得、架橋、補強、破壊、城攻撃、帰還のゲーム内SEをアクセントとして残す
- ナレーション中のBGMは十分に下げ、効果音は言葉を邪魔しない瞬間だけ強調する
- 最後のロゴ表示では短い上昇フレーズのあと、余韻を残して終える

## 正確性と禁止事項

- 試合時間は5分、城HPは15、各チームのBotは5体
- 橋は自陣専用2本と中央共有1本。中央は先に架けたチームが所有する
- 城への攻撃は1回1ダメージ。Bot同士は戦わない
- CPU難易度は「かんたん」「ふつう」「むずかしい」
- オンライン対戦はランダム対戦と数字5桁の専用部屋に対応
- 現在の公開URLは `https://infrarush.net/`
- フロントエンドをReact製と説明しない
- AWS基盤はTerraformで管理する正式な本番設計として紹介し、手作業で構築したように表現しない
- Terraformで未確認の具体的なモジュール名、リソース数、可用性数値、料金、性能値を捏造しない
- 「AIがユーザーごとにリアルタイムで勝手に難易度を変える」と表現しない
- 未実装機能、架空の受賞歴、未計測の人数・FPS・性能値を追加しない
- ポスターの画面や文字をそのまま並べるスライドショーにしない
- 画面録画を早送りして作業工程を理解不能にしない
- 子ども向けを理由に過剰な点滅、叫ぶ字幕、連続ズームを使わない

制作前に、実アプリをPC幅とスマートフォン幅で操作し、使う全機能が現在の画面と一致することを確認してください。収録時はデバッグ表示、ブラウザUI、個人情報、招待コードの使い回しが映らないようにします。
