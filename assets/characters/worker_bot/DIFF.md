# 作業 Bot の理想画像との差分

参考：`キャラデザ.png`。正面・背面・側面・3/4 図を比較した。

再現：大きな青い丸いヘルメット、白い顔と黒い楕円の目、橙色の安全ベスト、紺色の手袋・靴、低く丸い体形。

今回の差し替え：指定 Drive フォルダの `WorkBot.glb` をそのままゲーム用 GLB として採用。編集用 `.blend` は提供 GLB からインポートした。大きさをゲーム内の Bot 単位に合わせ、青・赤のチーム色と同梱の Idle / Walk / Wave / Blink アニメーションを接続した。

適用範囲：フィールド上で操作する Bot と、ショベル・ブルドーザー・グレーダー・架橋機・掘削機のキャビン内に見える搭乗 Bot。搭乗 Bot はゲーム表示時に車両の既存 Bot を隠し、同じ WorkBot を座席位置へ配置する。
