# 油圧ショベル：支給モデルとの差し替え

支給された `油圧ショベル.glb` を造形の基準にして置き換えた。正式なデザインシートと正面・背面・側面・3/4を比較し、白いキャビン、青いアームとバケット、橙色の後部、黒い履帯を確認した。ゲーム上ではBotの搭乗、採掘時の車体旋回・ブーム昇降・バケットの掘削と排出を確認した。

支給GLBは26メッシュ・78テクスチャ・約17.7万三角形で、アニメーションと関節階層はなかった。Blenderで車体・上部旋回体・ブーム・バケット・搭乗位置を分離し、大きなメッシュを簡略化して約11.6万三角形、7.8 MBにした。元GLBは `source/supplied-excavator.glb` に残し、編集可能なファイルは `source/excavator.blend` に保存した。

**残る制約：** ブームとディッパーは支給モデル内で一体のテクスチャ付きメッシュのため、肘関節だけを独立して曲げると形状が破綻する。現状は一体のアームを上下させ、バケットを独立して動かす。独立した肘の動きを加える場合は元メッシュの手動再モデリングとテクスチャ修正が必要。
